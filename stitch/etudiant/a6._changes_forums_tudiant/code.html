Problème d'implémentation du gradient dans la backprop manuelle (Ligne 42)

Bonjour à tous, lors du calcul de la dérivée partielle par rapport aux poids W2 dans le perceptron multi-couches sans autograd, ma matrice de jacobienne n'a pas les dimensions attendues lors de la multiplication tensorielle :

backprop_manual.py Python 3.11 
dW2 = np.dot(delta3, a2.T)  # ValueError: shapes (64,10) and (128,64) not aligned
db2 = np.sum(delta3, axis=0, keepdims=True)
psychology_alt
Réponse validée par Dr. H. Vasseur : "Attention à la transposition : pour respecter la convention batch-first, l'activation amont doit être transposée après la réduction de taille : np.dot(a2.T, delta3)."
